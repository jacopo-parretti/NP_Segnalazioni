# NP Segnalazioni

Drop-in rewrite of `NPmonitor` (submit) and `NPevo_nearmiss` (mcadmin). Same URLs, same CED_DB tables.

## Security

- **Reports** are encrypted in the submitter's browser (`nacl.box` to the manager's public key). The DB stores only `CIFRATO` and the receipt day. Kaizen and Near Miss stay plaintext.
- **Only mcadmin can read** them, in the browser. Login sends `md5(password)`, and `USERS` is never written. scrypt derives the key that opens the private key, held in `sessionStorage` until logout.
- **Emergency key**: shown once at setup. Print it; it opens the private key without the password.
- **Pinned key**: the form works only if the DB public key matches `impronta_chiave_gestore` in `NPmonitor/config.php`.
- **History**: legacy plaintext rows are encrypted, verified field by field, then cleared in one transaction. No row is ever deleted.
- **Secrets** live only in the git-ignored `config.php`, generated by `node tools/genera-config.js`.

Accepted risks:

1. IIS logs record the sender's IP and time.
2. No HTTPS: whoever can edit files on srv-web or tamper with the network can capture future reports or the mcadmin password.
3. Losing both the password and the emergency key makes the reports unreadable.
4. Backups taken before the migration hold the plaintext history.
5. mcadmin's md5 in `USERS` is brute-forceable.
6. `ced_db` is db_owner: it cannot read reports, but it can delete them.
7. An XSS on the same origin can read the key from `sessionStorage`.

## Workflow

- **Checks**: `node --test tests/` and `node tools/controlli.js`.
- **Local test**: run `prova\prova.cmd crea`, then `prova\prova.cmd`, then open `http://localhost:8090`.
  - It uses the `_PROVA` tables, with fake reports and Power Automate off.
  - After setting the key, run `prova\prova.cmd impronta <fingerprint>`.

**Deploy.** Rename the old folders on srv-web (never copy over them), then:

1. Run `node tools/genera-config.js` and copy `NPevo_nearmiss`.
2. As mcadmin, open Segnalazioni:
   - set the key and print the emergency key;
   - the history gets encrypted;
   - run `node tools/genera-config.js --impronta <fingerprint>`.
3. Copy `NPmonitor`.

**Recovery.** Use the recovery page with the emergency key or the old password.
